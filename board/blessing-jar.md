## 다른 세션에 알리는 노하우 (다른 앱에서도 써먹을 것)
- **흔들기 웹 점검**: 헤드리스 크롬에서 `window.dispatchEvent(new DeviceMotionEvent('devicemotion', {acceleration:{x,y,z}}))` 가 된다. 손가락 끌기 대체 조작도 같이 둬야 데스크톱·권한 거부에서도 막히지 않음.
- **iOS 흔들기 권한**: `DeviceMotionEvent.requestPermission()` 은 버튼 탭 안에서만 → "Turn On Shake" 버튼. 거부되면 끌기 안내로 바꾼다. 사파리는 `navigator.vibrate` 없음(햅틱은 네이티브에서).
- 2D 쪽지 물리: Verlet + 8 서브스텝 + 원 충돌 + 벽 선분(가장 가까운 점 밀어내기) + 한 서브스텝 이동 상한(R×0.45)이면 세게 흔들어도 샘 0 (로봇이 8초 스트레스로 검사).
- 버튼 높이 44 미만(목록 줄 오른쪽 'Remove'·'Add' 글자 버튼)을 로봇 `tapBtn` 높이 검사가 잡았다 — 글자 버튼도 `min-height: 44px`.
