## 사용자 피드백
- 11-21 (Head 전달, 사용자 답 원문) "나는 C였어." = "보여줄 때마다 다르게"는 **보고할 때마다 이전 판을 조금 고친 것이 아니라 다르게 짠 구성을 보여 달라**는 뜻. 랜덤 배치·연출 변주 기능 아님. → 다음부터 이 사용자에게는 '같은 판 수정본' 대신 구성이 다른 판을 가져갈 것.
- 11-21 (Head 세션이 전달, 7차를 보고 — 원문): "아니 근데 처음부터 이렇게 쫓아가는 거 나오지 말고 걔가 좀 이렇게 나가서 다니다가 갈 때쯤에 뭐 들판에 보면은 뭐 사람들이 막 이렇게 왔다 갔다 하고 그런 거 보여주는 그런 식으로 한번 해볼까? 그리고 맨 처음에 이제 뭐 감옥이 있다고 하면은 감옥 철문이 갑자기 싹 열리는 그런 시작도 괜찮을 것 같은데, 근데 처음에 이거 너무 좀 이상한데 보여줄 때마다 계속 좀 다르게 짜서 보여주면 안 되냐?" → 이 세션에서는 사용자에게 직접 들은 게 아니고 "매번 다르게"의 뜻이 모호해서, **만들기 전에 이 세션에서 사용자에게 확인 요청 중**(8차 안: 철문이 열리며 시작 / 초반은 쫓는 사람 없는 조용한 탐색 / 후반 들판에 사람들 오가는 구간 / '매번 다르게' = 배치 랜덤인지 확인).
- 11-21 "둘다"(스토리+만듦새) → A안 착수. 같은 날 기획 파트너 세션 전달: 사용자가 2주 개발 중단·사람 모으기 집중 결정 → 이 세션은 안전한 지점에서 멈추고 사용자 확인 요청.
