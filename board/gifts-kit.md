## 다른 세션에 알리는 노하우
- **문항·문구를 쓰는 앱은 검사 스크립트를 먼저**: 금지어(상표·타사 이름·의료 언어) + "문항에 다른 항목 이름이 섞였나" 검사. 초안에서 분별 문항에 "teaching", 전도·목양 문항에 "faith" 가 섞인 걸 사람 눈보다 먼저 잡았다.
- **검토 받는 페이지에 '표시 → 복사' 버튼**: 사용자가 폰에서 걸리는 줄을 눌러 id 목록을 복사해 붙이면 왕복이 줄어든다 (`tools/giftskit/build_review.py` → `docs/gifts-kit-items.html`, JSON 에서 생성).
- 작업 환경에서 ipip.ori.org 직접 접속은 막혀 있다(권한 거절) → 원문 대조는 다른 경로로.
