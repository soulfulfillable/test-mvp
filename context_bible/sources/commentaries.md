## 확인 결과 바뀐 것
- 47절 "야곱의 속임(창 27:35)과 대비"는 **열어 본 주석 어디에도 없었다**. 화면에서 "one possible reading"으로만 두고, 주석들은 야곱 연결을 51절에서 한다고 밝힘. 창 27:35 의 같은 낱말(LXX δόλος)은 원문 대조된 낱말 일치로만 표시.
- 46절 베들레헴 연결은 Chrysostom 이 실제로 말한다 → "One early reader, John Chrysostom, thought…"로 출처를 밝혀 서술. 반대 읽기(Augustine·Cyril)도 함께.
- 쓰지 않은 것: Theodore of Mopsuestia(나사렛 멸시설) — 파일에 출처 링크가 비어 있고 현대 번역(저작권 불명)으로 보여 근거로 쓰지 않음. Bonaventure — 한 줄만 확인, 미사용.
