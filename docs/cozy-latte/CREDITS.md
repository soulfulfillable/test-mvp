# Cozy Latte — Credits

- All code in this folder (`index.html`, `latte.js`, `qa/robot.js`) was written for this project. No third-party code, libraries, fonts, images or CDN files are used.
- The fluid simulation follows the standard, publicly documented "stable fluids" method (Jos Stam, 1999: semi-Lagrangian advection + pressure projection solved with Jacobi iteration on the GPU). It is an implementation of the published method, not a copy of anyone's source code.
- Cup, saucer, crema and the demo finger are drawn by code (shaders / inline SVG).
