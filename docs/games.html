Soulfulfill Games

Nine short, tap-only games. Each one is a single HTML file that runs in any phone browser.

  • Portrait, one-thumb play
  • 30 seconds to a few minutes a round
  • No install, no login, no external calls
  • Works offline after the first load

About

Soulfulfill is a one-person studio. Every game here is a self-contained file under 100 KB: no engine runtime, no fonts, no CDN, no analytics. Daily puzzles are seeded by the date so everyone plays the same board and the leaderboard is fair. Each game has a friend challenge link that puts your record on their screen.

Platforms: these games are built to fit instant-play catalogs such as YouTube Playables (portrait, single file, offline, one ad slot). Publisher channel: Peblit.
