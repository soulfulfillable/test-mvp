Privacy Policy

Peblit Uploader · Last updated October 6, 2026

Peblit Uploader is a private tool used only by the owner of the Peblit YouTube channel to upload videos and update channel details through the YouTube Data API. It is not offered to the public.

What it accesses

With the channel owner’s permission, the tool uses the YouTube scopes needed to upload videos, set thumbnails, update the channel description and banner, and change the visibility of the owner’s own videos.

What it stores

The tool does not collect, store or share any personal data. The only credential it keeps is an access token for the owner’s own channel, stored as an encrypted secret in the owner’s GitHub repository. No data from other people is accessed.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is never sold, used for advertising, or transferred to third parties.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
