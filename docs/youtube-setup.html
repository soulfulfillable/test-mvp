YouTube API 연결 (처음 한 번, 15분)

PC 에서 하세요. 끝나면 채널 정리·업로드는 전부 자동입니다. 모든 단계는 soulfulfillable@gmail.com 계정으로 로그인한 상태에서 합니다.

1. 구글 클라우드 프로젝트 만들기

  1. console.cloud.google.com/projectcreate 열기 → 프로젝트 이름에 아래 값 → 만들기.
프로젝트 이름
peblit-uploader
  1. YouTube Data API v3 페이지 → 위에서 방금 만든 프로젝트가 선택됐는지 확인 → 사용(Enable).

2. 동의 화면 (Google Auth Platform)

  1. Google Auth Platform → 시작하기(Get started).
  2. 앱 이름 아래 값, 지원 이메일 soulfulfillable@gmail.com → 다음.
  3. 대상(Audience): 외부(External) → 다음 → 연락처 이메일 soulfulfillable@gmail.com → 동의 체크 → 만들기.
  4. 왼쪽 브랜딩(Branding) → 앱 이름 Peblit Uploader, 사용자 지원 이메일, 애플리케이션 홈페이지·개인정보처리방침 링크(아래 두 주소), 승인된 도메인에 soulfulfillable.github.io, 맨 아래 개발자 연락처 이메일(soulfulfillable@gmail.com)을 채우고 저장. 로고는 비워 둡니다. 이걸 안 하면 Publish 버튼이 회색입니다.
  5. 왼쪽 대상(Audience) → 앱 게시(Publish app) → 확인. '테스트' 상태로 두면 연결이 7일마다 끊깁니다. 게시해도 심사 없이 본인 계정은 쓸 수 있습니다.
앱 이름
Peblit Uploader
애플리케이션 홈페이지
https://soulfulfillable.github.io/test-mvp/peblit.html
개인정보처리방침 링크
https://soulfulfillable.github.io/test-mvp/peblit-privacy.html
승인된 도메인
soulfulfillable.github.io

3. 열쇠(클라이언트) 만들기

  1. 왼쪽 클라이언트(Clients) → 클라이언트 만들기 → 유형 웹 애플리케이션.
  2. 승인된 리디렉션 URI → URI 추가 → 아래 값 → 만들기.
  3. 뜨는 창의 클라이언트 ID 와 클라이언트 보안 비밀번호 를 메모장에 잠깐 복사해 둡니다(다시 보기 어려움).
리디렉션 URI
https://developers.google.com/oauthplayground

4. 유튜브 권한 받기 (refresh token)

  1. OAuth Playground 열기 → 오른쪽 위 톱니바퀴 → Use your own OAuth credentials 체크 → 10번의 ID·비밀번호 붙여 넣기 → Close.
  2. 왼쪽 아래 Input your own scopes 칸에 아래 값 → Authorize APIs.
  3. soulfulfillable 계정 선택 → "Google에서 확인하지 않은 앱" 이 나오면 고급 → peblit-uploader(으)로 이동 → Peblit 채널 선택 → 허용.
  4. Exchange authorization code for tokens 클릭 → 나온 Refresh token 복사.
scope
https://www.googleapis.com/auth/youtube https://www.googleapis.com/auth/youtube.upload

5. GitHub 에 넣기 (3개)

  1. 새 Secret 만들기 열기 → Name 에 아래 이름, Secret 에 값 → Add secret. 3번 반복.

이 값들은 채팅에 붙여 넣지 마세요. GitHub Secret 에만 넣습니다.

이름 1 → 값: 클라이언트 ID
YT_CLIENT_ID
이름 2 → 값: 클라이언트 보안 비밀번호
YT_CLIENT_SECRET
이름 3 → 값: Refresh token
YT_REFRESH_TOKEN
