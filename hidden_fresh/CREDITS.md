# Credits — Odd Capy Out (Hidden Friends, fresh start)

- **Art**: all characters and scenery are original vector drawings written as SVG code in `game/index.html`
  (one palette, one 2.8-unit line weight, light from the top-left). No third-party images.
- **Sound**: synthesised live with the Web Audio API (oscillators). No audio files, so no CC0 credits needed.
- **Reference**: inspired by the *idea* in user screenshots of a YouTube Playables capybara-finding game.
  The original title was not identified and we did not play it; no images, layout or code were copied.
