## 이 채널만의 한 가지
**모든 소리를 코드가 만든다** → 저작권 0, Content ID 걱정 0, 곡이 무한. 남의 음원 라이브러리는 쓰지 않는다.
(재즈처럼 연주 뉘앙스가 큰 장르는 코드로 어렵다 → 앰비언트 패드·피아노 아르페지오·자연음·카페음부터.)

## 만들 것 (파이프라인, 전부 자동)
1. **생성 음악 엔진** (Python+numpy 또는 Node): 키·템포·화성 진행을 시드로 받아 — 패드(느린 코드 진행, 저역 통과), 피아노 아르페지오(랜덤 워크, 벨로시티 변화), 가끔 멜로디 조각, 긴 리버브. 영상 길이는 **1시간 30분**(2026-10-05 사용자 결정, 원안 8시간). **같은 곡 반복이 아니라 계속 변주**(유튜브 "반복 콘텐츠" 판정 회피 + 듣기 좋음).
2. **환경음 레이어**: 비(필터 노이즈+물방울), 모닥불(탁탁), 카페(웅성거림은 노이즈 밴드+컵 소리 샘플 합성), 바람, 파도. 전부 합성 — 녹음 샘플 안 씀.
3. **영상**: 코드로 그린 반복 그림(creative-coding: 비 내리는 창, 모닥불, 흔들리는 커튼) 또는 느린 색 변화 — 1080p, 8시간, ffmpeg 로 인코딩(`/usr/bin/ffmpeg` 있음).
4. **업로드**: YouTube Data API 로 제목·설명·챕터·썸네일 자동. (OAuth 는 사용자 Google 계정 `soulfulfillable` 1회 승인.)
5. **일정**: Actions 로 주 N 편 자동 생성·업로드. 시리즈: 비 오는 날 피아노 / 모닥불 밤 / 카페 아침 / 눈 오는 밤 …

## 원칙
- **중간 광고 없음**(참고 영상처럼 제목에 명시). 유튜브 수익은 앞·뒤 광고와 시청 시간으로.
- 유튜브 정책: 2025~26 "대량 생산·반복 콘텐츠" 수익 제한 → 영상마다 **실제로 다른 음악·다른 그림·다른 설명**, 시드 공개("Seed #1042" — 같은 걸 다시 들을 수 있음, 우리만의 재미).
- 수익 시작 조건: 구독자 1,000 + 시청 4,000시간(12개월) — **첫 수익까지 수개월**이라는 걸 사용자에게 미리 말한다.
- 신앙 시리즈는 같은 엔진으로 `plans/soaking-music-app.md` 와 공유.

## 수익화 거절 대비책 (처음부터)
- 영상마다 **다른 음악(시드 공개)·다른 그림·직접 쓴 소개 글**. 썸네일은 사람 손 느낌(코드 그림이어도 영상마다 다르게).
- 처음 10편은 **짧게(1~3시간)** 여러 분위기로 → 반응 좋은 걸 8시간으로. 처음부터 8시간 ×50개 금지(대량 생산으로 보임).
- 채널 소개에 "모든 소리는 직접 설계한 생성 시스템이 연주" 명시 — 투명성.
- 신앙 시리즈(기도·묵상)와 일반 시리즈(비·카페·모닥불)를 **같은 채널**에 둘지 따로 둘지는 첫 10편 반응 보고.
- 수익화 거절되면: 그래도 앱 홍보 통로로 유지(통독 앱 링크).
