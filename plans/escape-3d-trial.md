# 3D 탈출 장애물 코스 — 시험판 (기획 파트너, 2026-11-10, 사용자 "추천대로" = B)

## 순서
Playables 큐: Kitty Sudoku(라이브) → **Cozy Coloring(진행 중)** → **3D 탈출 시험판(이것)** → 데일리 솔리테어 → Tricky 두뇌 퍼즐. 색칠이 끝나고 사용자 확인 뒤 착수(한 번에 하나씩).

## 계기
사용자가 Playgama 의 "Escape fro…"(1,071 played, 주황 죄수복 캐릭터, 회색 콘크리트 통로·가시, 왼쪽 아래 조이스틱 + 오른쪽 점프 버튼, 3인칭 3D)를 보고 "이런 거는 못 만들어?". 그 게임을 복제하지 않는다 — 장르(3D 장애물 코스/탈출)만.

## 시험판 범위 (3~5일, 판단용)
- **캐릭터 1명**: 무료 CC0 3D 모델 팩(동작 포함: idle/run/jump/fall) — 출처·라이선스 CREDITS. 직접 그린 박스 인형 금지(Knock Chain 교훈). 다운로드가 이 환경에서 막히면 정확한 URL 을 "🖱️ Codex 에게"로.
- **조작**: 왼쪽 아래 가상 조이스틱 + 오른쪽 점프 버튼(폰), WASD/방향키+스페이스(데스크톱). 3인칭 카메라 자동 추적.
- **코스 1개(30~60초)**: 출발 → 가시 피하기 → 움직이는 발판 → 점프 구간 → 출구(문이 열리고 빛). 떨어지거나 가시에 닿으면 마지막 체크포인트로 즉시 복귀(게임 오버 없음).
- **첫 프레임에 목표가 보임**: 출구가 멀리서 빛나고, 첫 3초 안에 "저기로 가면 되는구나". 글 설명 없음.
- 엔진: three.js + 가벼운 물리(캐릭터 컨트롤러는 직접 또는 rapier/cannon-es 중 모바일 성능 좋은 쪽), 모바일 60fps 목표, 초기 로딩 < 5MB.
- 소리: 발걸음·점프·착지·체크포인트·출구(CC0).
- **안 하는 것**: 레벨 여러 개, 수집·스킨·상점·광고·Playgama 업로드. 판단용 시제품만.

## 검증
로봇: 출발→출구까지 자동 조작으로 완주, 가시 닿으면 체크포인트 복귀, 폰 390×844·작은 폰·데스크톱, 프레임 측정, 콘솔 0. 스크린샷을 처음 보는 사람 눈으로.
