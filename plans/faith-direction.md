# 장기 목표 — 말씀을 쉽게 만나고, 더 깊이, 자연스럽게 전하기 (기획 파트너, 2026-11-04)

- 카드3: 개발자가 교회의 원어 풀이 설교에서 영감 → 스크롤 + 성경 방식.

## 해석 (추론 — 기능 확정 아님)
사례에서 배울 것은 "성경 앱"이라는 장르가 아니라 세 가지 연결:
1. **익숙한 조작** — 사람들이 하루에 수백 번 하는 '위로 스와이프'로 말씀을 만난다(새로 배울 게 없음).
2. **궁금할 때만 더 깊이** — 기본은 읽기만, 누르면 설명(선택형). 첫 화면을 복잡하게 하지 않음.
3. **자연스럽게 전하기** — 크리에이터가 자기 이야기 속에서 한 문장으로 소개할 수 있을 만큼 단순한 가치.
게임화·메뉴·수집보다 **첫 화면에서 바로 가치가 느껴지는 경험**이 우선.

## 기존 아이디어와의 차이
- **Tolle(통독)**: "오늘 분량 체크 → 1년 지도" — 꾸준함·계획이 중심. 4.3 반려 상태. 사례는 계획이 아니라 '지금 한 구절'에서 출발.
- **Verse Weave(암송 퍼즐)**: 퍼즐 게임화 — 사례는 게임화를 덜어 낸 쪽.
- **Blessing Jar(가족 감사)**: 관계·나눔 — 말씀 자체보다 가족 대화.
- **잃은 양(Knock Chain, 중단)**: 메시지를 게임에 암시로 숨김(Playgama 종교 규칙 때문) — 사례는 말씀을 정면으로 보여 줌. **플랫폼이 다르다**: 이쪽은 App Store/웹의 신앙 카테고리, Playgama/YouTube Playables 가 아님.

**기획 파트너 추천(제안)**: **A 로 먼저 작게 검증, B 는 A 안의 '이야기 탭' 후보.** 이유: 콘텐츠를 한 번 고르면 끝나서 혼자 운영 가능하고, 첫 화면 한 번 누르면 바로 가치가 오고, 크리에이터가 한 문장으로 소개하기 쉽다. C 는 사례와 가장 가깝지만 번역 사용권과 복제 인상이 걸려 뒤로.

## 아직 정하지 않은 것 / 나중에 검토
- **번역 사용권**: NLT·NIV 등은 저작권이 있어 앱에 넣으려면 허가·인용 한도 확인 필요. 공개 도메인(KJV, WEB — World English Bible)은 자유. 첫 검증은 공개 도메인 번역으로.
- **AI 설명**: 넣는다면 성경 본문(번역 출처)과 해석(AI·주석)을 화면에서 분명히 구분, 원어 풀이의 정확성 검수, 호출 비용. **지금 구현하지 않음.**
- 수익: 사례의 유료 AI 모델을 따를지는 미정. 광고는 말씀 앱 경험과 충돌 가능 — 나중에.
- 플랫폼: App Store 는 계정 4.3 상태(대표 앱 Kitty Queens 진행 중)라 제출 간격·차별점 설명이 필요. 첫 검증은 웹 미리보기.
