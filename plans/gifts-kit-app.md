## 구성
1. **은사 진단** (핵심): 로마서 12장·고린도전서 12장·에베소서 4장·베드로전서 4장의 은사 목록(가르침·섬김·긍휼·권면·구제·다스림·지혜·믿음·전도 등)으로
   **문항을 새로 작성**(약 60~80문항, 5점 척도). 결과: 상위 은사 3개 + 각 은사 설명 + 관련 성경 구절(WEB) + "이렇게 섬겨 볼 수 있어요" 제안.
2. **기질 진단**: IPIP Big Five 공개 문항(퍼블릭 도메인, 상업 사용 가능)을 바탕으로 문항을 다듬어 사용. 결과는 5가지 성향 막대 + 쉬운 설명.
3. **둘이 비교**: 결과를 짧은 코드(약 20자)·QR 로 → 상대 코드 입력하면 나란히 비교 + "서로 이렇게 도울 수 있어요".
4. **소그룹 지도 (리더 키트)**: 리더가 멤버 코드 여러 개 입력 → 모임의 은사 분포·빈 은사·역할 제안. PDF/이미지로 내보내기.
- 모든 데이터는 기기 안에만. 서버·계정 없음.
