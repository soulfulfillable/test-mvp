# 차기작 후보 3 + 추천 1 (기획 파트너, 2026-11-02) — 기획만, 구현 금지

## 기준 (사용자 2026-11-02)
기존 9개·Knock Chain 변형에 제한하지 않음. 좋은 그래픽은 장기 목표(이번 절대 조건 아님). **①즉시 이해되는 조작·목표 ②손맛과 연결된 반응(두더지의 타격 반응은 괜찮다는 피드백) ③짧은 판 + 재도전/성장 ④자연스러운 선택형 광고 ⑤비잔인 ⑥혼자 제작·운영 가능.**
교훈 반영: 첫 프레임에 주인공·목표·조작 대상이 크게 보여야 하고 글로 설명하지 않는다(Knock Chain 실패). 탭 순환+페널티 금지, 규칙 2개 이하(CvD 교훈). 콘텐츠는 코드가 만들거나 아주 작게(색칠 앱 교훈). Playgama 4.2.2(카탈로그 내 복제 금지) 때문에 **흔한 장르라도 한 가지 분명한 변형**이 필요.

## 후보

### 1. 정렬 퍼즐 "Pen Sort"(가칭) — 공/물 정렬(ball sort) 계보
- **첫 20초**: 색이 섞인 우리(pen) 4~5개, 같은 색 동물만 한 우리에 모으면 끝. **탭 1(꺼낼 우리) → 탭 2(넣을 우리)**. 맨 위 색만 움직이고 같은 색 위에만 올라간다 — 규칙 2개, 화면에서 보임.
- 손맛: 동물이 폴짝 뛰어 옮겨 가고, 우리가 완성되면 문이 닫히며 "딸깍"+반짝. 반응은 두더지처럼 즉각.
- 판 길이/성장: 레벨 30~90초, 레벨 수 무한(코드 생성 — 역방향 섞기로 **항상 풀리는 판** 보장), 난이도 = 우리 수·색 수·빈 우리 수.
- 선택형 광고: 막혔을 때 **되돌리기 5회 / 빈 우리 1개 추가**(2.2.3 "추가 보너스", 시도당 1회), 레벨 끝 전면 광고(Bridge 가 타이밍 결정).
- 비잔인: 동물 돌보기.
- 혼자 범위: 2D Canvas, 에셋 = 동물 실루엣 6색·우리 1종·효과음 5개. **아트 요구 가장 낮음.** 1~2주.
- 변형(4.2.2 대비): **밤 + 등불** — 한 우리는 어두워 맨 위 색만 보이고 옮기면 밝혀진다(기억 요소), 또는 **잃은 양 1마리**가 매 레벨 어딘가 숨어 있어 다 정리하면 나타난다(사용자 주제를 암시형으로 계승, 노출 수위 A).
- 시장: Block Out!·Magic Sort 가 우리 조사(10-19)에서 3주 연속 미국 상위. 정렬 게임은 포화 — 변형 없이는 묻힌다.
- 위험: 포화·복제 인상. 변형이 "뭔지 모르겠다"가 되면 안 됨 → 변형은 1개만.

### 2. 떨어뜨려 합치기 "Fruit Drop Merge"(가칭) — 수박 게임(Suika) 계보
- **첫 20초**: 위에서 과일을 **좌우로 움직여 탭으로 떨어뜨림**. 같은 과일끼리 닿으면 합쳐져 한 단계 큰 과일. 통이 넘치면 끝. 설명 없이 3초 안에 읽힌다.
- 손맛: 물리 충돌·튕김·합쳐질 때 "퐁"+커짐 — **매 탭마다 반응**. 물리는 Planck.js(Knock Chain 에서 결정론 구현 경험 있음, MIT).
- 판 길이/성장: 한 판 2~5분(다른 후보보다 김), 성장 = 최고 점수·최대 과일 도달, 데일리 시드 판으로 랭킹 공정(우리 강점).
- 선택형 광고: 넘치기 직전 **"작은 과일 3개 제거"** 1회, 또는 되돌리기 1회. 판 끝 전면 광고.
- 비잔인.
- 혼자 범위: 2D Canvas + Planck. 에셋 = 과일 11단계 원형 그림(그라데이션 원으로도 통함)·효과음. 1~2주.
- 변형: 과일 대신 **고양이 11단계**(우리 Kitty 시리즈 연결) 또는 **달·행성**. 합체 시 짧은 표정 애니메이션.
- 시장: 2023~24 세계적 히트, 클론 매우 많음(Playgama 4.2.2 위험 가장 큼, 변형 필수).
- 위험: 한 판이 길어 "30초~1분" 원칙과 어긋남, 복제 인상, 물리 튜닝(운처럼 느껴지면 실패).

### 3. 베기 타이밍 "Slice Rush"(가칭) — 과일 베기/퍼펙트 슬라이스 계보
- **첫 20초**: 도마 위로 재료가 지나가고 **탭 한 번에 칼이 내려온다**. 선 안에서 자르면 퍼펙트, 벗어나면 망침. 점점 빨라지고 재료가 바뀐다.
- 손맛: 칼 내려찍기·단면·조각 튕김·"탁" — 두더지 타격감과 같은 계열(반응속도+타이밍).
- 판 길이/성장: 45초~1분, 콤보·퍼펙트 연속, 재료 해금.
- 선택형 광고: 실수 1회 이어하기, 특수 칼 체험.
- 비잔인(음식).
- 혼자 범위: 가장 작음(1주). 에셋 = 재료 8종 단면·칼·효과음.
- 변형: **리듬**(재료가 박자에 맞춰 옴, 음악과 동기) 또는 **주문표**(손님이 원하는 두께).
- 시장: 하이퍼캐주얼 고전, 상위 표본엔 없음(10-31 표본 8개 기준).
- 위험: 두더지와 같은 "반응속도" 축이라 **포트폴리오가 또 비슷해 보임**, 판단 거리 짧음(사용자가 지적한 "탭→결과").

## 독립 추천: **1. 정렬 퍼즐 "Pen Sort"** (변형 1개 = 잃은 양 1마리 숨김)
이유: ① 조작이 탭 2번으로 끝나 **설명 없이 읽힌다**(Knock Chain 실패의 정반대) ② 레벨이 30~90초, 레벨 수 무한 = 짧은 판+성장을 둘 다 만족, 레벨은 코드가 만들고 항상 풀림 ③ 선택형 광고 자리(되돌리기·빈 우리)가 규칙 2.2 에 정확히 맞고 자연스럽다 ④ 아트 요구가 가장 낮아 혼자 운영 가능하고, 좋은 그래픽은 나중에 에셋만 갈아끼우면 된다 ⑤ 우리 조사에서 현재 미국 상위에 있는 유일한 유형 ⑥ 두더지(반응)와 축이 달라 포트폴리오가 "비슷한 앱 양산"으로 보이지 않는다 ⑦ 사용자 주제(끝까지 찾는 양 한 마리)를 암시형으로 자연스럽게 담을 수 있다.
2순위 = 2(합치기): 손맛은 최고지만 판이 길고 복제 위험이 가장 크다. 3(베기)은 두더지와 겹쳐 제외.

**다음(승인 뒤에만)**: Pen Sort 첫 프레임 1장(주인공=우리와 동물, 목표=완성된 우리 1개 예시, 조작=손가락 2탭 유령 표시) → 사용자 "뭘 하는지 알겠나" → 통과 시 레벨 5개 코어 테스트.
