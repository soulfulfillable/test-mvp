# 신박한 앱 아이디어 모음 (기획 파트너, 2026-10-05~)

사용자 요청: "가끔 신박한 앱도 하나씩 기획해 주라. 예: 투자받은 신앙 메신저인데 건전하게만 쓰이게 설계됨."
조사 한계: 평점 수는 검색 요약값, 일부 기사 원문은 프록시 차단.

## 심리·은사 진단 앱 평가 (사용자 아이디어, 2026-10-05)
- **수요**: 일반 성격 테스트는 크지만 **투자받은 앱이 장악**(Dimensional 8.7천·4.9★ 다중 프레임워크+친구 비교, Boo 21만). 기독교 은사 진단은 iOS 에 **거의 없음**(최대 13 평가) — 경쟁 없음 = 앱스토어 수요도 작음(웹·PDF 로 함, ChurchGrowth.org 자칭 800만 명).
- **저작권·상표 (핵심)**: MBTI·Myers-Briggs·16 Personalities·5 Love Languages 는 상표 → 이름·키워드·UI 에 금지. 에니어그램 RHETI·Lifeway/Fuller/Team Ministry 은사 진단지 모두 저작권 → 문항 그대로 못 씀.
  **쓸 수 있는 것**: IPIP Big Five 문항(퍼블릭 도메인, 상업 사용 명시) → 4글자식 결과로 재해석 가능. 은사는 **성경 본문(롬12·고전12·엡4·벧전4)으로 문항을 새로 작성**. 은사 이름(가르침·긍휼·섬김…)은 자유.
  ⚠️ openpsychometrics 의 OEJTS 는 **CC BY-NC(비상업)** → 광고 앱에 못 씀.
- **심사**: "임상·심리 진단 아님, 자기 성찰용" 표기. 서버·계정 없으니 개인정보 부담 적음. 4.3 대비 "오프라인 소그룹 키트"라는 분명한 차이 필요.
- **빈자리**: 결과 **코드/QR 로 둘이 비교 + 리더가 8명 코드 넣으면 모임 은사 지도** — 경쟁 앱들은 전부 계정 필요(Love Nudge 1위 불만이 로그인·동기화 실패).
- **결론**: 수익 면에선 유틸 파이프라인을 못 이긴다. 그러나 **"소그룹 은사·기질 키트"** 로 좁히면 경쟁 0·사역 가치 큼 → 신앙 앱 슬롯 후보로 **성경 통독 체크·Verse Weave 와 함께 비교**. 수익은 무료 + 결과 화면 배너 + "리더 키트" 1회 $4.99~9.99(교회는 소액 지출에 관대).
