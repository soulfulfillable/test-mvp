# Playables 핵심 재미 점검 — 9개 게임 비교와 대표 1개 개선 방향 (기획 파트너, 2026-11-01)

사용자 문제 제기(11-01, Codex 경유): "지금 게임들이 너무 단순하고 일차원적, 탭→결과만 있는 것 같다. Hamster Escape 처럼 **계속 움직이는 조작·회피·공간 반응·이어지는 애니메이션**과 뭐가 다른가."

**관찰**
- Hamster Escape 류(Supersonic 카탈로그: Stacky Dash, Hide N Seek, Bazooka Boy, My Mini Mart)의 공통점 = **손가락을 떼지 않는 연속 조종(드래그/조이스틱) + 2D 공간에서 경로를 고르는 회피 + 레벨 단위 진행(클리어→다음 레벨) + 매 레벨 끝 보상 화면.** 우리 9개 중 이 네 가지를 동시에 가진 게임은 **없다.** 연속 조종은 Climb or Burn·Poop Dodge 둘뿐이고, 레벨 단위 진행은 Catdoku 뿐이다(퍼즐).
- "탭→결과" 느낌의 원인은 조작이 **이산적(탭 1회 = 사건 1회)**이고 **판단 거리가 1초 안쪽**이라서다. 공간을 읽고 경로를 고르는 시간이 없다.
- 하이퍼캐주얼 시장 근거(10-30 조사·Supersonic 목록 플레이 수 1,800만~7,300만): 상위권은 전부 **연속 조종·레벨형**. 반응속도 단독 게임(두더지류)은 목록에 없었다. (표본 = 사용자 캡처의 Supersonic 페이지 1장 — 전체 카탈로그 통계가 아님.)

## 3. Chicken Cross 개선 방향 (제안 — 사용자 OK 뒤 개발 세션)
핵심은 그대로(탭 전진, 콤바인 추격, 기차 경고등, 조크). 얹는 것은 **공간 판단과 진행 단위** 두 가지뿐.
1. **가로 이동**: 좌/우 스와이프(또는 화면 좌우 1/3 영역 탭)로 한 칸 옆으로 — "이 차선은 막혔으니 옆으로 돌아가자"가 생긴다. 탭 전용 원칙은 유지(스와이프는 탭의 확장, 홀드 없음).
2. **차선 다양화**: 통나무 떠내려오는 강(타고 이동), 멈춘 차(장애물), 신호등 횡단보도(안전 구간) — 각 차선이 다른 판단을 요구.
3. **구간(zone) 진행**: 50칸마다 구간 전환(농장→마을→고속도로→밤), 구간 끝에 "GOOD JOB!"식 짧은 결산 화면 → 여기가 상자 진행 바·보상 제안(망치 수집과 같은 A 방식)의 자리. 날짜 시드·랭킹은 유지.
4. **캐릭터 스킨 1종류**(닭 품종/모자 — 원작 디자인): 수집 보상. 플레이 중 항상 보이는 주인공이라 꾸미기 효과가 망치보다 크다.
5. **연결 애니메이션**: 전진 점프 호(arc)·착지 스쿼시·깃털, 구간 전환 카메라 이동 — "이어지는 움직임" 느낌.
먼저 웹 미리보기(`docs/chicken-cross.html` 은 그대로 두고 복사본)에서 1·2·5만 넣어 사용자 느낌 → OK 면 3·4 → Playgama 판.
