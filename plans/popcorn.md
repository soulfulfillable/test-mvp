# Popcorn (가칭 "Pop & Topple") — 팝콘 물리 조준 게임 (기획 파트너, 2026-11-02, 사용자 제작 승인)

## 한 줄
작은 옥수수 **씨앗을 뒤로 당겨** 방향·세기를 정해 **틈으로 쏜다** → 짧고 분명한 예고(떨림·김) 뒤 **팝콘으로 크게 부푼다** → 팽창·접촉 힘으로 받침·컵·상자 구조물이 **실제 물리로 흔들리고 무너진다** → **표시된 목표물을 바닥에 떨어뜨리면 성공.** 핵심 판단 = "**어디에 끼워 넣어 팽창시키는가**"(공 스킨만 팝콘인 게 아님).

## 스토리 (2026-11-02 사용자 "스토리부터." — 개발 세션 제안, 승인 대기)
**"팝(Pop)과 배고픈 강아지 버터"**
- 주방 바닥에 사는 강아지 **버터**는 팝콘을 제일 좋아하는데, 팝콘 통은 늘 손이 안 닿는 높은 선반 위에 있다.
- 작은 옥수수 알갱이 **팝**은 뭘 들어 올리지도 못하는 제일 작은 녀석이지만, 딱 하나 할 줄 아는 게 있다 — **틈에 끼어서 "펑" 하고 부풀기.**
- 팝은 새총(버터의 간식 숟가락)을 타고 날아가 틈에 끼고, 펑 터져서 선반·기둥을 밀어 **팝콘 통을 버터 앞에 떨어뜨린다.**
- 레벨마다 통이 더 교묘한 곳에 있고(열린 틈 → 옆구리 → 좁은 틈 → 도미노 → 두 번) 버터는 그 아래에서 입 벌리고 기다린다. 통이 떨어지면 버터가 받아먹고 꼬리를 흔든다. 씨앗을 다 쓰면 버터가 낑낑댄다(게임 오버 아님, 바로 다시).
- 마지막(5) 뒤: 배부른 버터가 팝을 핥아 준다 — "Best. Kernel. Ever."
**첫 화면이 말하는 것**: 아래에 입 벌린 버터(주인공·왜) · 위 선반의 팝콘 통(뭘) · 틈(어디) · 숟가락 위의 팝(조작). 글 없음.

## 레벨 5개 (짧게, 각 10~30초)
1. **Open Gap** — 큰 열린 틈 하나. 거기 넣으면 한 발에 성공(첫발 이해 확인용). 목표물 = 틈 위 선반의 컵.
2. **Side Push** — 정면이 막힘. 옆 틈으로 넣어 팽창 힘이 기둥을 옆으로 밀어야 목표가 떨어짐.
3. **Narrow Slot** — 좁은 틈. 세기 조절(너무 세면 튕겨 나감, 약하면 못 들어감).
4. **Chain Collapse** — 받침 하나를 터뜨리면 위 상자 탑이 도미노처럼 무너져 목표가 떨어짐(연쇄 붕괴).
5. **Two Seeds** — 씨앗 2개로 2단계: 첫 팝으로 길을 열고 둘째 팝으로 목표를 떨어뜨림.
씨앗 수: 레벨 1~3은 3개, 4는 3개, 5는 4개(튜닝은 로봇 결과로). 다 쓰고 목표가 안 떨어지면 실패 → **즉시 재시도**(같은 화면, 1탭). 성공 = 목표물이 바닥(또는 접시)에 닿음, 화면에 "Target down!".

## 화면·조작
- **밝은 배경**(주방/스낵 테이블, 2D 또는 2.5D). 첫 화면에 **크게**: 씨앗 발사 위치(발사대/숟가락) · 목표물(색 테두리 + 작은 깃발 아이콘) · 도착지(바닥/접시).
- 손 드래그 안내(처음 1회, 손가락 아이콘이 뒤로 당기는 애니메이션) + 짧은 궤적 예고(점선, 처음 몇 점만).
- 폰 세로 터치 드래그 + 데스크톱 마우스 드래그, 둘 다. 당기는 동안 세기 게이지.
- HUD: 남은 씨앗(아이콘 n개), 목표 색과 남은 목표 수 — **판정과 일치**(표시된 것만 세고, 떨어지면 즉시 줄어듦). 레벨 번호, 재시작 버튼, 음소거.
- 팽창 예고: 씨앗이 멈춘 자리에서 0.4~0.6초 떨림+김 → "펑" 하고 반지름 4~6배로 부풀며 주변을 밀어냄. 팽창은 물리 바디 반지름 증가 + 접촉 충격(과한 카메라 흔들림 없이 충돌음·팝 소리·변형·튀는 움직임으로 원인→결과가 보이게).

## 기술
- 물리: **Planck.js**(Box2D, MIT — Knock Chain 에서 결정론 구현 경험 있음: 고정 타임스텝 1/120, 난수 없음 → 같은 당김 = 같은 결과). 팽창은 fixture 교체 또는 반지름 보간(안정성 확인). 모바일 성능: 바디 수 ≤ 40, 60fps 목표, 번들 ≤ 1MB.
- 렌더: Canvas 2D(응집된 스타일: 같은 팔레트·같은 광원·바닥 그림자 통일). three.js 불필요.
- 에셋: 직접 그린 벡터/캔버스 + 라이선스 확인 효과음(CC0, Kenney 등; `CREDITS.md`). 팝 소리는 실제 음원(합성 금지 습관 유지).
- 제약 아님: 단일 파일·100KB·무엔진. 필요한 만큼 쓰되 로딩 1초 안쪽.
- 폴더: `playables/popcorn/`(src, levels.js, build.sh, robot.cjs, qa/) → `docs/popcorn/`(빌드 결과) + `docs/popcorn.html`(소개·링크).
- 문구 전부 영어. 스튜디오 표기 **Treasurefield Studio**(사용자 11-02). "시장 최초" 류 주장 금지.
