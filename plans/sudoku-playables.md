# Kitty Sudoku (가칭) — 숫자 스도쿠, Playgama/YouTube 용 (기획 파트너, 2026-11-08, 사용자 A 승인)

## 왜
사용자(11-08): "캣도쿠 뭔가 바로 규칙 알려 주는 게 안 되는 것 같애, 다 어떻게 하는지 한참 뒤에 알아서. 그냥 진짜 숫자로 하는 스도쿠 만들어 볼까." → Queens 류는 규칙 3개가 낯설다. **숫자 스도쿠는 설명 0** — 유튜브(3초 안에 읽혀야 함)에 맞다. 포화 장르라 "복제" 위험은 있음 → 작은 차별점만.

## 규칙·UI = 시중 표준 그대로 (새로 만들지 말 것)
- 표준 스도쿠 규칙. 9×9(3×3 박스), 6×6(2×3 박스), 4×4(2×2 박스).
- UI: 숫자패드 · Notes(연필) · Undo · Erase · 같은 숫자 하이라이트 · 선택 칸의 행/열/박스 하이라이트 · 틀린 입력 빨간 표시(옵션: 실수 3회 제한 — 기본 ON, 시중 다수가 그렇게 함) · 타이머 · 일시정지 · 남은 숫자 카운터(패드에 각 숫자 남은 개수).
- **설명 화면 없음.** 첫 판은 4×4 쉬운 판으로 시작하면 그 자체가 튜토리얼.
- 난이도: Easy/Medium/Hard + 레벨 진행(4×4 → 6×6 → 9×9 Easy → …). 생성기는 유일해 보장(백트래킹 + 대칭 제거), 시드 고정.

## 차별점 (가설 — 유일하다고 주장하지 않음)
1. **짧은 판 중심**: 4×4·6×6 레벨을 섞어 1~3분 판 기본(유튜브·버스). 9×9 도 있음.
2. **데일리 + 친구 도전장**: 날짜(KST) 시드로 모두 같은 판, 도전 링크 열면 친구 기록이 화면에 같이 뜸(계단·캣도쿠 엔진 재사용). 랭킹은 푼 시간.
3. **고양이 마스코트**: 규칙엔 손 안 댐. 판 옆에서 고양이(호랑이 Horangi 그림 재사용)가 입력·실수·완료에 반응, 완료 시 짧은 축하. Kitty Queens 브랜드 유지.
- 안 하는 것: 변형 규칙, 킬러/대각선 등 모드, 상점·결제·로그인.

## 기술
`playables/sudoku/` — Kitty Queens Playables(`playables/catdoku/`)의 배관 복사: Bridge SDK 어댑터·storage·오디오 컨트롤러(CC0)·광고(전면: 판 완료 / 보상형: 힌트 1칸·실수 3회 뒤 이어하기 1회, 2.2 규칙)·반응형(1:1·가로)·로봇. 웹 미리보기 `docs/sudoku-playables/`. 이름 표기 **Kitty Sudoku**(가칭 — 상표 충돌 조사 뒤 확정).

## 검증
로봇: 4×4·6×6·9×9 각 3판 실제 풀이(풀이기), 노트·되돌리기·지우개·하이라이트·실수 제한·이어하기, 데일리·도전장 링크, 14개 크기, 콘솔 0. 보고: 미리보기 링크 + 스크린샷(첫 판, 9×9) + 질문 1개("설명 없이 바로 됐나").

## 안 하는 것
