# Verse Weave — 성경 암송 퍼즐 (기획 파트너, 2026-10-06)

사용자: 신앙 앱 후보 추천 순서대로 진행 (`plans/novel-ideas.md` 1순위).

## 이 앱만의 한 가지 (4.3 대비)
**매일 성경 한 절이 퍼즐로 변하고, 풀다 보면 외워진다.** 암송 앱(Bible Memory 3.3만, Versify 1.5만 평가)은 전부 플래시카드·타이핑 — 퍼즐 생성기 방식은 없다.

## 게임
- 오늘의 한 절(날짜 시드, 모두 같은 절) → 3단계로 점점 어려워짐(같은 절을 3번 다르게 만나며 외워짐):
  1. **단어 순서 맞추기**: 섞인 단어 타일을 끌어 문장 완성.
  2. **빈칸 채우기**: 단어 일부가 빠짐, 아래 타일에서 골라 넣기(팔레트 방식 — CLAUDE.md "탭 순환 금지").
  3. **첫 글자만**: 각 단어 첫 글자만 보이고 타일로 채우기.
- 규칙은 화면에 보이게, 2개 이내. 틀려도 하트 깎지 않음(암송은 벌점 X) — 대신 다시 시도, 힌트.
- 완성 시 시그니처: 절 전체가 한 줄씩 차분히 나타나고(조용한 애니메이션) 장절 표시. 연속 기록은 작게.
- **내 암송 목록**: 외운 절 모아 보기, 복습(간격 반복: 1·3·7·14일).
- 번역: **WEB(World English Bible, 퍼블릭 도메인)**. KJV 는 영국 왕실 저작권 → 미국만이면 가능하나 처음엔 WEB 만.
- 절 선정: 잘 알려진 암송 구절 365개 목록을 직접 구성(장절 목록만, 본문은 WEB 에서) — 출처·선정 기준 기록.
- 캣도쿠·Kitty Path 의 날짜 시드·보상형·광고 처리 구조 재사용(`catdoku_app/`, `kittypath_app/`).

## 원칙 (신앙 앱)
- 퍼즐 푸는 화면엔 광고 없음. 완성 화면·목록 화면 배너만. AdMob 민감 카테고리 차단, Religion 허용. 보상형은 "힌트"만, 영상 없으면 무료로.
- `DESIGN.md` 새 앱 규칙 적용(시스템 글꼴, Cupertino, 강조색 1개, 이모지 아이콘 금지). 단어 타일은 차분한 종이 느낌.
- 영어 UI, 아이폰 전용·세로, 오프라인.
