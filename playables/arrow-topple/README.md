# Arrow Topple — tools

Game files live in `docs/arrow-topple/` (no build step): `index.html`, `game.js` (drawing, input, sound), `sim.js` (physics, also runs in node), `planck.min.js`.

- Solver: `NODE_PATH=<folder with planck@1.5.1 in node_modules> node playables/arrow-topple/tools/solve.cjs`
- Robot: `NODE_PATH=/opt/node-tools/node_modules node playables/arrow-topple/robot.cjs` → `qa/report.json` + screenshots

Credits: physics by Planck.js 1.5.1 (MIT, Erin Catto / Ali Shakiba). All drawings and sounds are generated by our own code.
